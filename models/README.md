# Пользовательские веса

Положите сюда доверенный `my_model.pt` или экспортированный YOLO `model.onnx`.
В Docker каталог доступен как `/custom-models`, например:

```sh
MODEL_PATH=/custom-models/my_model.pt docker compose up --build
```

Перед первой сборкой скачайте `yolo11n.pt` в эту папку: Docker копирует
локальный файл в `/models/yolo11n.pt`, а не скачивает его автоматически.
Для основной конфигурации команды также нужен `yolo11s.pt`.
Ссылки на веса и порядок установки приведены в
[инструкции для команды](../README.md#2-скачать-веса-детектора).
Весовые файлы исключены из git.
