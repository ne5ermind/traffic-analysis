# Функциональные требования проекта InnovaTransport

## Функциональные требования

### ФТ-1. Загрузка видеозаписи

Система должна предоставлять пользователю возможность загрузить видеозапись транспортного или пешеходного потока для последующего анализа.

**Критерии:**

- Пользователь может выбрать видеофайл на устройстве.
- Система принимает поддерживаемый формат видео.
- После выбора файла пользователь может запустить его загрузку.
- Система сообщает об успешной загрузке видео.
- При загрузке некорректного или неподдерживаемого файла система сообщает об ошибке.

### ФТ-2. Автоматический анализ видеозаписи

Система должна выполнять автоматизированный анализ загруженной видеозаписи с использованием методов компьютерного зрения.

**Критерии:**

- Пользователь может запустить анализ загруженного видео.
- После запуска система автоматически обрабатывает видеозапись.
- Во время обработки пользователь видит состояние анализа.
- После завершения обработки система формирует результаты.
- При возникновении ошибки система сообщает пользователю о невозможности завершить анализ.

### ФТ-3. Обнаружение объектов

Система должна обнаруживать транспортные средства и пешеходов на видеозаписи.

**Критерии:**

- Система распознаёт транспортные средства в кадре.
- Система распознаёт пешеходов в кадре.
- Обнаруженные объекты учитываются при дальнейшем подсчёте.
- Один и тот же объект не должен определяться как новый объект на каждом последовательном кадре.
- Результаты обнаружения должны быть доступны после завершения обработки.

### ФТ-4. Классификация объектов

Система должна разделять обнаруженные объекты по категориям.

**Критерии:**

- Транспортные средства и пешеходы учитываются отдельно.
- Для транспортных средств предусматривается разделение по поддерживаемым системой категориям.
- Каждый обнаруженный объект относится к соответствующей категории.
- Количество объектов рассчитывается отдельно для каждой категории.
- Результаты классификации отображаются пользователю.

### ФТ-5. Подсчёт транспортных и пешеходных потоков

Система должна автоматически определять количество транспортных средств и пешеходов, прошедших через рассматриваемый участок.

**Критерии:**

- Количество транспортных средств подсчитывается автоматически.
- Количество пешеходов подсчитывается автоматически.
- Один объект не должен учитываться несколько раз при одном прохождении зоны подсчёта.
- Система формирует итоговое количество объектов.
- Результаты подсчёта разделяются по категориям объектов.

### ФТ-6. Настройка зоны подсчёта

Система должна предоставлять возможность определить область или линию, относительно которой производится подсчёт объектов.

**Критерии:**

- Пользователь может задать область или линию подсчёта на изображении с камеры или видеозаписи.
- Выбранная зона визуально отображается пользователю.
- При анализе учитываются объекты, пересекающие заданную область или линию.
- Пользователь может изменить заданную область.
- После изменения области анализ может быть выполнен повторно.

### ФТ-7. Отображение результатов анализа

Система должна предоставлять пользователю результаты анализа транспортного и пешеходного потока.

**Критерии:**

- Отображается общее количество обнаруженных объектов.
- Отдельно отображается количество транспортных средств.
- Отдельно отображается количество пешеходов.
- При наличии нескольких категорий отображается количество объектов каждой категории.
- Полученные показатели отображаются в понятном для пользователя виде.

### ФТ-8. Визуализация результатов

Система должна визуализировать результаты автоматического анализа.

**Критерии:**

- Результаты могут быть представлены в виде таблиц, графиков или диаграмм.
- На визуализации должны быть различимы разные категории объектов.
- Визуализация должна формироваться на основе результатов анализа.
- При выполнении нового анализа данные визуализации должны обновляться.
- Пользователь должен иметь возможность определить основные показатели потока по представленной визуализации.

### ФТ-9. Просмотр обработанной видеозаписи

Система должна предоставлять пользователю возможность просматривать анализируемую видеозапись вместе с результатами работы алгоритма.

**Критерии:**

- Пользователь может воспроизводить видеозапись.
- На видео могут отображаться обнаруженные системой объекты.
- Пользователь может видеть принадлежность обнаруженного объекта к определённой категории.
- На видео должна отображаться заданная зона или линия подсчёта.
- Отображаемые на видеозаписи данные должны соответствовать результатам анализа.

### ФТ-10. Сохранение результатов анализа

Система должна сохранять результаты выполненного анализа для последующего использования.

**Критерии:**

- После завершения обработки результаты не должны исчезать при переходе к их просмотру.
- Для анализа сохраняются итоговые значения подсчёта.
- Сохраняются результаты по отдельным категориям объектов.
- Сохранённые данные не должны самопроизвольно изменяться.
- Результаты должны быть связаны с соответствующей видеозаписью.
