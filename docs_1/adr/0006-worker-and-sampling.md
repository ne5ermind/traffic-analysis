# ADR-0006: Фоновый worker и выборка кадров

- **Статус:** принято
- **Дата:** 2026-10-17
- **Модули:** `app/worker.py`, `app/sampling.py`

## Контекст

Анализ видео занимает минуты и не должен блокировать HTTP-сервис. На CPU обработка каждого кадра может превысить целевое время.

## Решение

Запускать CV-конвейер в отдельном worker. Задачи берутся из SQLite; один lock не даёт запустить два worker над одним хранилищем. Кадры выбираются по timestamp, а при риске превысить бюджет частота снижается.

## Последствия

- API сразу возвращает `run`, а frontend опрашивает статус.
- Heartbeat позволяет обнаружить зависший worker.
- Снижение FPS ускоряет анализ, но может пропустить короткие события.
