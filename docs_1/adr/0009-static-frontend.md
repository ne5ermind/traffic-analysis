# ADR-0009: Статический frontend без framework

- **Статус:** принято
- **Дата:** 2026-10-17
- **Модуль:** `static/`

## Контекст

Интерфейс состоит из одного рабочего экрана и запускается вместе с локальным API. Отдельная Node-сборка усложнит установку и сдачу проекта.

## Решение

Использовать HTML, CSS и модульно организованный vanilla JavaScript. FastAPI отдаёт статику. Состояние выбранных video, scene и run хранится в одном клиентском state. Сетевые ошибки проходят через общую функцию `api()`.

## Последствия

- Нет отдельного frontend build-step и дублирования деплоя.
- Canvas-overlay может синхронизироваться с HTML5 video без стороннего player.
- При значительном росте UI потребуется разбиение `static/app.js` на модули или переход на framework.
