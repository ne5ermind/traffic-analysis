# ADR-0005: YOLO, WBF и ByteTrack для CV-обработки

- **Статус:** принято
- **Дата:** 2026-10-17
- **Модули:** `app/model.py`, `app/ensemble.py`

## Контекст

Нужно обнаруживать шесть классов COCO и сохранять идентификатор объекта между кадрами. Проект должен работать на CPU и не выдавать фиктивные результаты при ошибке модели.

## Решение

Быстрый режим использует одну YOLO11s. Точный режим объединяет две YOLO через Weighted Boxes Fusion. После фильтрации валидные рамки передаются в один ByteTrack. Веса загружаются только из `data/models/`.

## Последствия

- Быстрый и ансамблевый режимы имеют общий формат детекций.
- Слабые рамки могут поддерживать трек, но новый трек требует более высокой уверенности.
- Ансамбль значительно медленнее и не гарантирует лучшую точность без эталона.
