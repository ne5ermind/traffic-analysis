# Проверка версии 2026-11-26

Проверка выполнена на ветке `codex/night-clusters-react`. Пользовательские исходные данные в репозиторий не добавлялись.

## Автоматические проверки

- `pytest -q tests`: 60 тестов, включая API, геометрию, ROI, ByteTrack, ночную обработку, нормализацию классов ночной модели, кластеризацию, метрики и ограниченную очередь декодирования.
- `python -m compileall -q app tests scripts`: пройдено.
- `npm run build`: React/esbuild и CSS собраны локально.
- `docker compose config --quiet`: конфигурация корректна; API ограничен 1 CPU, worker — 3 CPU.
- Браузерный smoke: 1440×1000, 390×844, 844×390 и 320×720. Проверены загрузка сохранённого результата, выбор night/ensemble/fast, ручные линии, сохранение зоны, добавление события, XLSX и отсутствие горизонтального переполнения.

## Реальная обработка

Короткий локальный фрагмент длительностью 12 секунд обработан на CPU с режимом night: 72 кадра инференса из 360 декодированных, 6,80 с, 10,59 кадр/с инференса. Это smoke работоспособности, не оценка качества.

NF-01 проверен полным видео, без экстраполяции:

| Параметр | Значение |
|---|---:|
| Длительность видео | 905,47 с |
| Docker / Python | Linux arm64 / Python 3.11.17 |
| Лимит контейнера worker | 3 CPU (`cpu.max = 300000 100000`) |
| Резерв API по Compose | 1 CPU |
| Время с загрузкой модели | 760,55 с (12 мин 40,55 с) |
| Инференс | 1991 кадр; 2,63 кадр/с |
| Декодировано | 27 149 кадров |
| Результат NF-01 | PASS, ≤ 30 мин |

Worker адаптивно снизил выборку до 2 кадр/с, как предусмотрено для соблюдения времени. Это может пропустить коротко видимые объекты, поэтому производительность и качество принимаются раздельно. Полный артефакт: [`benchmark-full.json`](./benchmark-full.json).

## Границы доказанного

- Обработка выполняется собственным локальным worker без стороннего видеосервиса.
- F-01, F-02, F-06—F-10 и нефункциональные свойства, не требующие размеченного CV-эталона, проверены автоматикой и браузерным сценарием.
- F-03—F-05 функционально реализованы и покрыты синтетическими/контрактными тестами. Точность на реальном видео не заявляется: размеченного дневного/ночного набора нет.
- Специализированные ночные веса не созданы, потому что нет размеченных ночных данных. Night использует коррекцию яркости и обычную локальную модель. Интерфейс, конфигурация, class mapping и скрипт обучения отдельной модели готовы.
- MAE/RMSE/WAPE и Precision/Recall/F1/MOTA/IDF1 возвращаются только после загрузки независимого эталона. Число обнаружений или визуальная яркость не считаются метрикой качества.
