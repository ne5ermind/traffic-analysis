# ADR-0003: HTTP API на FastAPI

- **Статус:** принято
- **Дата:** 2026-10-17
- **Модуль:** `app/main.py`

## Контекст

Интерфейсу нужен локальный HTTP API с валидацией запросов и понятной документацией.

## Решение

Использовать FastAPI и Pydantic. Маршруты группируются по ресурсам, Swagger формируется из кода, а долгая CV-обработка не выполняется в HTTP-запросе.

## Последствия

- `/docs` и `/openapi.json` всегда соответствуют рабочим маршрутам.
- Ошибки ввода возвращают единообразные HTTP-статусы.
- `app/main.py` остаётся точкой сборки и может расти; бизнес-логику нужно сохранять в отдельных модулях.
