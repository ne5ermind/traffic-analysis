# ADR-0009: React-интерфейс с локальной статической сборкой

- Статус: принято, обновлено 2026-11-26 по рекомендации преподавателя
- Модули: frontend/, scripts/build-frontend.mjs, app/main.py

React управляет состоянием и отображением интерфейса. Компоненты разделены по сценариям: архив, видео/overlay, конфигурация, результаты, редактор событий. HTTP-клиент и опрос API вынесены отдельно. При смене видео/запуска запросы отменяются; старые рамки очищаются.

Esbuild собирает React и ReactDOM в локальный bundle; Tailwind собирает существующую палитру приложения. FastAPI раздаёт артефакты, Docker собирает их отдельным Node-этапом. При работе не нужны Node-процесс и CDN. Прежний интерфейс без компонентов заменён.
