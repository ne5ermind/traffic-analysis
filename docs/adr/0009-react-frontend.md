# ADR-0009: Модульный frontend на React

- **Статус:** принято
- **Дата:** 2026-10-17
- **Модули:** `frontend/`, `static/`

## Контекст

Интерфейс вырос до полноценного рабочего пространства: загрузка видео, разметка зон, управление анализом, canvas-overlay, отчёты, картограмма и редактирование событий. Монолитный `static/app.js` затрудняет развитие, повторное использование UI и проверку изменений.

## Решение

Использовать React 18 и Vite. Исходный код хранится в `frontend/src`: визуальные блоки разделены на компоненты, клиентское состояние и сценарии API вынесены в `useTrafficAnalysis`, отрисовка overlay — в отдельный хук, сетевой слой и утилиты не зависят от представления.

Vite собирает приложение в `static/`, поэтому FastAPI продолжает отдавать интерфейс по прежнему адресу, а отдельный frontend-сервер в production не нужен. Docker собирает интерфейс на отдельном Node-этапе и переносит готовую статику в Python-образ.

## Последствия

- Компоненты можно изменять и проверять независимо, не раздувая единый скрипт.
- Canvas-overlay остаётся синхронизирован с HTML5 video без стороннего player.
- В разработке требуется Node.js, а CI и Docker выполняют обязательную Vite-сборку.
- Production-развёртывание остаётся единым: браузер получает готовые файлы через FastAPI.
