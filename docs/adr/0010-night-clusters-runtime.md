# ADR-0010: Локальная обработка ночного видео и кластеризация

- Статус: принято
- Дата: 2026-11-26

Видеофайл декодируется собственным worker в ограниченную очередь, детекции передаются одному трекеру в хронологическом порядке. PyTorch использует два потока, декодер — один; Compose резервирует worker 3 CPU и API 1 CPU. Нельзя параллельно вызывать один stateful-трекер на независимых кадрах.

Освещение выбирается day/night/auto; auto сглаживает яркость и использует гистерезис. Ночной baseline корректирует яркость; отдельная модель необязательна, но её отсутствие явно обозначено. Смена модели не сбрасывает трекер.

После завершения направленные траектории группируются DBSCAN, шум сохраняется отдельно. Артефакты clusters.json и performance.json записываются атомарно. Метрики качества считаются только при предоставлении эталона. См. RESEARCH_AND_EVALUATION.md и VERIFICATION.md.
