# Текущий процесс

Составлено по [расшифровке интервью](interview.txt), исходный DOCX сохранён
в родительской рабочей папке. Ранее существующего AS-IS.md в папке не было.

1. Для транспортного проекта выбирают перекрёсток.
2. Получают запись городской камеры или организуют съёмку на телефон.
3. Специалист последовательно просматривает направления движения,
   считает транспорт и пешеходов по 15-минутным интервалам.
4. Результат проверяют, затем оформляют Excel и иногда картограмму.
5. Потоки используют для калибровки моделей и обоснования дорожных решений.

Указанный ориентир трудозатрат — 5–6 часов на перекрёсток; он зависит
от сложности узла и качества записи. Типичные наблюдения: по 30 минут
утреннего и вечернего пика, иногда целые сутки. Проблемы: окклюзии,
низкое разрешение, неодинаковые ракурсы, трудоёмкость повторной проверки.
