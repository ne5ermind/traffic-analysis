# Предположения и способы проверки

| Предположение | Решение первой версии | Проверка |
|---|---|---|
| Камера неподвижна в пределах ролика | Координаты зон и траекторий в плоскости кадра | Просмотр образца записи |
| Доступны MP4 или MOV с декодируемой видеодорожкой | FFmpeg + OpenCV, проверка первого кадра и выборки | Upload и pipeline tests |
| Потоки повторяются | DBSCAN по траекториям, редкие движения остаются unknown | Эталон заказчика |
| Короткие перекрытия допустимы | ByteTrack + консервативное соединение фрагментов | Тест окклюзии, проверка на реальном перекрёстке |
| Идентичность при выходе и возврате неизвестна | Новый трек после длительного исчезновения | Ручная валидация |
| Сервер работает в доверенной сети | Нет регистрации, loopback-порты по умолчанию | Конфигурация развёртывания |
| Допустимый процент ошибки зависит от проекта | Настраиваемый порог, без обещаний точности | Задать порог в UI |

Это проектные предположения, а не подтверждённые метрики модели.
