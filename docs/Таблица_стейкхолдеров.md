# Стейкхолдеры

| Роль | Задача | Ценность | Критерий приёмки |
|---|---|---|---|
| Транспортный планировщик | Получить матрицу потоков | Меньше ручного просмотра | Видео → потоки → XLSX |
| Проверяющий | Оценить достоверность | Траектории, overlay, эталон | Видимая ошибка по классу/направлению |
| Руководитель проекта | Снизить трудозатраты | Автоматизация повторяемого процесса | Время анализа измеряется |
| CV-разработчик | Улучшить распознавание | Заменяемый detector | Замена модели без правок UI/API |
| Администратор | Запустить и хранить данные | Docker, локальное хранение, удаление | Воспроизводимый запуск и диагностика |

Названия ролей выведены из интервью, персональные данные не собираются.
