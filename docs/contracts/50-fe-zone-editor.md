# Контракт #50: редактор зоны

Issue: https://github.com/ne5ermind/traffic-analysis/issues/50

Editor поддерживает entry, exit, ROI, undo и числовой ввод. Точки хранятся в `[0,1]` относительно области кадра. Entry/exit завершается после двух точек; ROI — явно и минимум с тремя. Имя линии непустое и уникальное.

При edit event frontend передаёт `version`. На `409` диалог не теряет данные, список перечитывается. После правки обновляются events, KPI и графики.
