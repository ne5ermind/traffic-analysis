# План реализации

Исходное состояние: в рабочей папке отсутствовал репозиторий приложения; присутствовала
расшифровка интервью «Новая запись 8.docx». Оригинал сохранён, текст — `interview.txt`.

1. FastAPI, SQLAlchemy, локальное хранилище с заменяемым интерфейсом, Redis/RQ.
2. YOLO11n → независимый ByteTrack → потоковая запись наблюдений в SQLite.
3. Сглаживание, восстановление коротких разрывов, кластеризация траекторий,
   ручные зоны/линии, агрегация по классам и времени.
4. React + TypeScript + Vite: проекты, прогресс, редактор зон, результаты,
   видео с интерактивным overlay и картограмма.
5. Локальный AI-аудит после детекции: тип перекрёстка, активные подходы,
   качество кадров, согласованность треков и безопасная коррекция геометрии.
6. XLSX/CSV/JSON/SVG, сравнение с ручным эталоном.
7. Unit/API/integration tests, реальный detector smoke, production build и Docker.

Vite выбран вместо Next.js: приложение без SEO и SSR, статический frontend проще
разворачивать через nginx. Палитра нейтральная: подтверждённого брендбука нет.
Цвета не выдаются за фирменные. Никаких вымышленных результатов в интерфейсе.
